The test

Web Application Penetration Test — $5,500 flat

One web application, tested white-box/gray-box: you give us staging access, test accounts for each role, and any architecture documentation you can share. More context means deeper testing.

What gets tested

  • Authentication and session management
  • Authorization — including clinical vs. administrative role separation
  • Input validation: injection, cross-site scripting
  • Business logic and API endpoints
  • Healthcare-specific checks: PHI in responses, exports, error messages, and logs

What you receive

  • Full findings report — severity, evidence, reproduction steps, remediation
  • Attestation letter for buyer and auditor requests
  • 60-minute remediation call with your team
  • One retest within 30 days, with an updated attestation

Method

Checklist-driven, healthcare-aware

Testing follows the OWASP Web Security Testing Guide — a published, repeatable methodology — with additional checks written specifically for applications that handle protected health information.

Staging and synthetic data only

Testing never touches a production system or real patient data. If a staging environment with synthetic data isn't available, we will help you scope getting one — we won't test production instead.

Evidence you can act on

Every finding ships with evidence and reproduction steps, rated by severity, with remediation written for your engineers — and a plain-language summary for the buyers who asked for the test.

Critical findings don't wait

If testing turns up a critical vulnerability, you hear about it the same day — not for the first time in the final report.
